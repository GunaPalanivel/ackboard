# ADR 003: rename from Vigil to Sevboard

Date: 2026-09-01
Status: accepted

The first working title collided with deadbits/vigil-llm, an LLM security scanner. The replacement is Sevboard: a severity board. npm, GitHub, and DNS checks for that exact spelling were clean on 2026-09-01. A fashion shop named sevaboard (extra a) is a different word.
