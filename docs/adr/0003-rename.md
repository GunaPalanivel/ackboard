# ADR 003: rename to Ackboard

Date: 2026-09-02
Status: accepted

Working titles along the way:

1. Vigil. Dropped after it collided with deadbits/vigil-llm, an LLM security scanner.
2. Sevboard. A severity board. npm and GitHub were clean, but the name came from an AI shortlist, and the hackathon rules ask a human to pick.
3. Ackboard. The name the human picked. "Ack" is what you do to a page. npm was free. GitHub had only two tiny unrelated repos (achow101/ackboard, CybSekFR/AckBoard).

This file is the only place the old titles should still appear.
